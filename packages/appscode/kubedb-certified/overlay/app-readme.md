# KubeDB

[KubeDB](https://kubedb.com) by [AppsCode](https://appscode.com) makes running production-grade databases on Kubernetes easy. It supports a wide range of popular databases including PostgreSQL, MySQL, MongoDB, Elasticsearch, Redis, Kafka, MariaDB, and more.

## Features

- **Day 2 Operations**: Automated backup, restore, failover, scaling, version upgrades, and TLS management
- **Multiple Databases**: PostgreSQL, MySQL, MongoDB, Elasticsearch, Redis, Kafka, MariaDB, ClickHouse, Druid, FerretDB, MSSQLServer, Memcached, PgBouncer, ProxySQL, RabbitMQ, Solr, ZooKeeper, and more
- **Monitoring**: Built-in Prometheus metrics and Grafana dashboard support
- **GitOps Ready**: Works with FluxCD and ArgoCD for GitOps workflows
